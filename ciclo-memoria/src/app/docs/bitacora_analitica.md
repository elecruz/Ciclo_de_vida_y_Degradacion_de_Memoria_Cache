## Demostración de PVI Operativo
Al evaluar el PVI de la letra del problema `x(1)=1, y(1)=1` en la solución general `x³ = C(y² - x²)`, el denominador se anula provocando una discontinuidad (el sistema colapsa).

Para que el MVP de software pueda graficar la curva real de degradación, el equipo de ingeniería determinó utilizar el **PVI Operativo: x=1, y=2**, lo cual da como resultado:
* C = 1/3
* y = √(3x³ + x²)
